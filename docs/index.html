Banco de pruebas — Sunmi Print Bridge

Cada botón dispara window.location.href = "sunmiprint://print?data=…" — la app puente lo recibe, decodifica los bytes ESC/POS y los manda directo a la impresora térmica integrada. Sin diálogo de impresión, sin PDF de por medio.

Cómo leer el resultado

  1. 1 Al tocar un botón, Chrome debería preguntar una vez si quiere abrir "Sunmi Print Bridge" — permite siempre.
  2. 2 La app aparece medio segundo (pantalla transparente) y suelta un aviso: "Ticket enviado a la impresora" o el error exacto.
  3. 3 Si no aparece ningún aviso ni pasa nada, revisa que el APK esté instalado y que el permiso de origen desconocido siga activo.
  4. 4 Errores de "servicio no encontrado" → el terminal no tiene el servicio de impresión Sunmi corriendo (raro, pero pasa tras un reset de fábrica).
